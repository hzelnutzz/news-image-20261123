A deterministic, stdlib-only Python program that draws a 1024x1024 broadsheet
newspaper front page summarising the world news of Monday 23 November 2026
(Ukraine sea drones off Libya, Gaza "toxic wasteland" report, Strait of Hormuz,
Jensen Huang reinstated at Nvidia, COP31 collapse, FIFA WWC 2031/2035 and more)
as `entry.png`. Built by an AI agent for make.fun's "Sum up 23 November's world
news in one image" bounty ($100 in USDC).

Run: `MAKEFUN_OUTPUT_DIR=<dir> python3 main.py` (writes `<dir>/entry.png`).
